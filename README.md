# ОСБ — редактор документов

Статический сайт для заполнения РП-документов ОСБ на основе Typst-шаблонов.
Выбор шаблона сверху, живое превью, экспорт в PDF и JPG (постранично).

## Запуск

Нужен только HTTP-сервер (открытие через `file://` не подтянет шаблоны) и интернет
(компилятор Typst, шрифты по умолчанию и pdf.js грузятся с CDN):

```bash
cd OSB-site
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Деплой на GitHub Pages

1. Залить корень папки в репозиторий.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Сборка не нужна.

## Возможности

- Табы шаблонов: Требование / Проверка / Отстранение. Черновик каждого хранится отдельно.
- Постоянные данные (сотрудник, начальники, телефон) — один набор на все документы.
- Автосейв всего в `localStorage`: `osb_profile_v1`, `osb_draft_<шаблон>_v1`, `osb_template_v1`.
- Своя подпись: загрузка PNG/JPG, чистка белого фона, ширина слайдером. По умолчанию
  встроена стандартная подпись из шаблонов. Подписи в штампах «Согласовано»/«Вручение» —
  текстом (можно вписать фамилию).
- Штампы «Согласовано ОСБ/ГУ» — галки «поставить» + дата. Подпись, ФИО и должность
  берутся из постоянных данных (раздел «Начальник ОСБ/ГУ»).
  «Копия верна» — всегда, только должность + звание + ФИО сотрудника.
  «Отметка о вручении» — галка + дата/время, получивший подставляется сам
  (проверка/отстранение — сотрудник из документа, требование — ознакомленный).
  «Отстранить / не отстранять» — переключатель.
- Проверка: данные сотрудника вводятся один раз (подразделение, звание из списка, пол,
  фамилия, инициалы), формулировки «в отношении / за кем надзор / кого отстранить-уведомить»
  собираются кнопкой «⟳ Собрать формулировки» (звания и фамилии склоняются автоматически,
  собранное можно править). № проверки = № постановления. Стандартный абзац блока
  «Установил» дописывается автоматически.
- Левая и правая панели — равной ширины, разделитель между ними тянется мышью (запоминается).
- Экспорт: PDF (вектор из Typst), JPG постранично (scale 3, качество 0.92), исходник `.typ`.
- Валидация обязательных полей блокирует экспорт с подсказкой.

## Структура

```
index.html / style.css / app.js   — приложение (без сборки)
templates/*.typ                   — параметрические шаблоны (единственный источник вёрстки)
templates.js                      — те же шаблоны, вшитые для работы через file:// (генерируется!)
assets/gerb.svg, sign-default.png — герб и стандартная подпись
assets/*.js                       — те же файлы + шрифты в base64 (сгенерированы, для file://)
assets/fonts/LiberationSerif-*.ttf — точные шрифты для WASM-компилятора
tools/test-data.py                — подмена DATA-блока + `typst compile` (синтаксис, escaping, ветки #if)
tools/check-fields.py             — сверка `#let v-*` в .typ с DATA_KEYS в app.js
tools/make-assets.py              — регенерация assets/*.js из картинок
```

## Как добавить поле

1. Добавь `#let v-имя = "..."` в `// <OSB-DATA>` блок нужного `templates/*.typ` и используй в теле.
2. Добавь ключ в `DATA_KEYS[шаблон]` в `app.js`.
3. Добавь значение в `buildData()` и поле в `DOC_SCHEMAS`/`PROFILE_SECTIONS`.
4. Перегенерируй вшитые файлы и проверь:
   `python3 tools/build-templates.py && python3 tools/check-fields.py && python3 tools/test-data.py all`.

## Если пишет NetworkError / не грузится превью

- Нужен интернет: компилятор Typst (~8 МБ), pdf.js и шрифты по умолчанию грузятся с CDN.
  Без интернета работают только формы (данные сохраняются локально).
- Файл можно открывать двойным кликом (`file://`) — все локальные данные вшиты в страницу.
  Если ошибка осталась — открой консоль браузера (F12) и посмотри, какой запрос упал.

## Примечания

- Штампы стоят на фиксированных позициях (`#place`, dy 245–249мм) и могут налегать
  на нижнюю подпись — так задумано в исходных шаблонах (полупрозрачные оверлеи).
- Для точной вёрстки WASM-компилятор использует встроенные Liberation Serif
  (`assets/fonts/`); без них (offline/file://) подставится DejaVu Serif и постраничность
  может отличаться.
